# NoInstallPlayer

Play videos and music straight from your browser, with nothing to install.

**▶ Open it:** https://eduspruce.github.io/NoInstallPlayer/

## What it does
- Opens local files (drag and drop or Ctrl+O) and network links (Ctrl+N)
- Playlist with search, shuffle, repeat, and M3U import/export
- Subtitles (.srt / .vtt) with delay sync and size control
- 10-band equalizer with presets and pre-amp, volume up to 200%
- Video effects (brightness, contrast, rotation…), aspect ratio, frame capture
- Speed from 0.25× to 4×, A→B loop, frame-by-frame
- Keyboard shortcuts similar to classic desktop players (F1 shows the list)

Everything runs on your machine: the files are never uploaded anywhere.
Plays any format the browser supports (MP4/H.264, WebM, MP3, OGG…; MKV depends on the codec).

## Run it locally
Download `index.html` and open it in any browser. It also works offline.
